# External replay of ScienceQA rankings and WinoGrande selection

15 November 2026. All experiments in this directory analyse existing public outputs. No model inference, new benchmark submissions or manuscript edits were performed for this audit.

## ScienceQA

The ScienceQA leaderboard lists GPT-3 (CoT, QCM-ALE) at 75.17% in its Avg column. Twenty other Avg entries cite the same MM-BigBench study. We audited the entire cited block after identifying the mismatch in the adjacent LaVIN-7B comparison. This source-block census is retrospective. The source population is the 2,017 test questions with images. We joined the published subset by instance ID to ScienceQA, verified equality of all 2,017 reference labels, and verified that its ID set is exactly the set with an image in the official 4,241-item split.

GPT-3 obtained 3,188/4,241 on the original scored outputs, and 1,360/2,017 (67.43%) on that study's image subset using exactly the same stored predictions and scoring. LaVIN-7B's published best-of-ten prompt score on that population is 75.11% (1,515/2,017 is the unique compatible integer count). The apparent 0.06-point GPT-3 lead becomes a 7.68-point LaVIN lead. The source-block census changes four strict pairwise orderings (LaVIN-7B, BLIP-2, InstructBLIP and ChatGPT), and the Flan-T5-XXL comparison becomes a tie at reported precision. Fifteen comparisons preserve their original ordering. The 20 comparisons share a single source block and a single GPT-3 arm. They are not 20 independent replications.

For the competing models we verified the source study's published aggregates, its actual test file and labels, and the original table. Its public repository supplied small output examples, but we did not locate the full original LaVIN-7B outputs. The four orderings refer to the published evaluation configurations, which used different models and prompting strategies. There is no all-4,241-question LaVIN result here. In the CSV, `implied_correct` is reconstructed only when unique under standard rounding. The published Lynx value is not compatible with an integer numerator on 2,017 items under that rule and is left blank. It does not affect any reversal.

The same scope error is visible in MiRA, Table 4. It lists the LaVIN-7B score as 75.11 in AVG and marks IMG unavailable. Its methods explicitly restrict its own experiment to questions containing images, while Table 5 gives MiRA 96 in both columns and section 5.2 draws conclusions about the overall benchmark. The described experiment identifies performance only on the image population. The other 2,224 questions require predictions to identify a full-test average. No corrected whole-benchmark MiRA accuracy or SOTA ranking is known from this audit.

## Empty outputs and assigned options

The ScienceQA authors archived GPT-3's raw text and the assigned option index for all 4,241 questions. Their published driver calls `random.choice` for failed extraction. In total 243 texts are empty, and 123 corresponding saved options match the official gold. Giving no credit for an empty answer, changing nothing else, yields 3,065/4,241 (72.27%), a fall of 2.90 percentage points. Of the 243 blanks, 225 have two options and 118 of those earn credit. Of 249 total native-parse failures, the remaining six are nonempty. The native parser finds multiple answer statements; recovering the in-range leading answer explicitly promised by QCM-ALE gives 3,066 correct. Allowing all six nonblank cases to vary gives 3,061 to 3,067 correct. These are finite-record identification bounds, not confidence intervals. On the image subset 28 of 65 blanks received credit, yielding 1,332/2,017 (66.04%) under the blank-zero rule. The four primary ranking reversals require none of these score changes.

The 123 credits were counted from the decisions archived by the authors. A separate uninterrupted single-seed replay reproduced the two in-context training positions and 129 of 249 fallback choices. Historical checkpoint/retry state cannot be reconstructed from these files. The causal reason for each empty output is unknown.

The original paper reports direct-answer GPT-3 at 73.97%, implying 3,137 correct on the full panel. The reported CoT lead was 51. Under blank-zero, if the direct run had 72 original credits on blanks it would tie the corrected CoT result. Fewer than 72 would reverse the comparison, more would retain the CoT advantage. Only the CoT original outputs were present in the authors' release. The direct-arm result after the same correction is unidentified. The upstream commit introducing the public results and scorer was 360b71cb6a36b9e3161dc9b65e9d86458b7d13a3 (17 October 2022).

The two LLaVA archives provide a control with original texts for both sides. Neither contains blanks. The v0 JSON header reports 3,855 while the saved indices yield 3,856; v1.3 has 3,863 in both. Allowing all unresolved texts to vary gives v0 3,855–3,856, v1.3 3,863–3,867. The winner is fixed throughout this interval.

## Independent WinoGrande test

Before looking at the archived predictions we fixed the Pythia-160M and Pythia-12B comparison, and predicted that a constant B answer key would reduce the 12B model's advantage. The original five-shot Open LLM Leaderboard likelihoods reproduce all 2,534 per-item correctness indicators. The official totals are 653 vs 813 out of 1,267; the deliberately collapsed rule gives 603 vs 651. The margin falls from 160 to 48 items (12.63 to 3.79 percentage points). This scoring intervention is hypothetical for Hugging Face. Its historical scores were correct. It is a test of the consequence of collapsing the answer key, not a replay of the One-Eval prompt-repair interaction or a replication of the Qwen–GLM comparison.

For the disjoint selection check we excluded all option groups containing any of the 234 known prior ledger item hashes. This removed 268 questions, leaving 485 for selection and 514 for assessment. Both rules chose Pythia-12B in selection; the loss on the separate 514-item assessment was zero. The excluded set is also shown in the JSON so its different ordering cannot be mistaken for a replication.

## Reproduction

From this directory, run `python audit_science.py --fetch` for ScienceQA. For WinoGrande, install pyarrow (the collecting job used 18.1.0) and run `python audit_wino.py --fetch`. Both read data from immutable revisions. The public Pythia files have SHA-256 digests in wino_sources.json. The official ScienceQA gold file was checked against its Git blob and independently cross-checked against a rendering of the 4,241 test answer letters and choice counts. Each of the 2,017 image golds is additionally corroborated by the MM-InstructEval file. The local dated protocols distinguish decisions made before reading responses from subsequent exploratory comparisons.

The results directory contains one row per item and model for ScienceQA, a paired WinoGrande ledger, summaries and the complete source-block ranking table. Indices in ScienceQA CSVs are zero-based. A parser value of -1 records unresolved output. A +1 rank in leaderboard_comparisons.csv favours GPT-3, -1 favours the comparator, and 0 is a tie at published precision.
