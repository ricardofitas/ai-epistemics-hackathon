# Archived WinoGrande validation

Recorded before calculating either model's accuracy or constant-reference score from the public rows. The two preferred public model archives were retrieved. They both contain 1,267 two-option records. The published larger model aggregate was known from the literature, and one row was inspected to establish the raw format. This is a private analysis lock, not an independent public preregistration.

The primary prediction is that the larger model's public gold-score advantage contracts when the reference is fixed to option 2 for both models. A true wrong selection is a separate, stricter outcome; keep ties and failures. Verify every row's official correctness against the archived Boolean value and the argmax (ties favour the first option as in the authored harness). Also compute official versus collapsed selection on one subset, and measure the selected model's official loss on a disjoint subset.

Remove every group containing a source item from the two available earlier Epistemics WinoGrande ledgers (234 unique sources across the two). Group by the unordered pair of stripped, case-folded choice strings; this keeps twins sharing choices together and can conservatively group unrelated items. Group key: UTF-8 SHA-256 of the canonical sorted two-string JSON array (compact separators and no ASCII escaping). Even first digest byte = selection, odd = independent assessment. Do not move items after viewing predictions. The published runs used log-likelihoods with five demonstrations. Applying a constant reference is a simulation of the One-Eval scoring rule and does not imply an error in the published Pythia scores.
