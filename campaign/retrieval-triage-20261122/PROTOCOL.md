# Round 05: Do extra retrieval competitors improve failure triage?

Question: Does exact leave-one-term-out search add actionable confidence information beyond a cheap top-two check? If the answer is yes, a system that sends low-confidence queries for review could justify checking additional competitors at fixed review coverage. The strongest simple explanation is that low margins and query length already explain fragility. A further plausible mechanism is that whole-corpus changes under term removal mostly introduce irrelevant alternatives, especially when removing a necessary term changes the information need.

This pilot is incremental. Yom-Tov et al. already showed query-term deletion features for query difficulty. Saleminezhad et al. learn context-sensitive term perturbations. Holdcroft et al. find strong score-distribution baselines for abstention across retrievers. This test asks whether paying to compare the rest of the corpus adds value beyond a matched runner-up deletion control in BM25, with no target calibration. Ranking robustness or term deletion alone is established. [Yom-Tov et al. 2005](https://www.yom-tov.info/Papers/SIGIR2005.pdf) · [Saleminezhad et al. 2026](https://doi.org/10.1145/3779428) · [Holdcroft et al. 2026](https://arxiv.org/abs/2609.15578)

Use BEIR SciFact train to fit the confidence functions and its official test split for the pilot. Use BEIR ArguAna test as a separate transfer task, without refit or target tuning, only if the pilot passes. Publish SHA-256 and check the official archive MD5. Queries come from the respective qrels split, with judged positive relevance defined by qrel >0. Unjudged top results count as misses. The outcome is top-1 judged hit, so incomplete qrels can misclassify a relevant top result. Exclude same-ID query documents on both datasets before all calculations. [BEIR release and checksums](https://github.com/beir-cellar/beir) · [BEIR paper](https://arxiv.org/abs/2104.08663)

Rank using BM25 with k1=1.2, b=0.75, positive Robertson IDF, Unicode case-folded alphanumerics, title concatenated with body, and unique in-vocabulary query terms. Break document ties by lexical ID. Score confidence with L2 logistic regression (mean logistic loss plus 0.01 times half the squared standardized coefficient norm, excluding the intercept). The baseline sees log query length, log in-vocabulary length, log top score, log top-1/2 and top-1/10 gaps, log standard deviation of the top ten, mean/max term IDF, and the fraction of term deletions that preserve the original winner against the original runner-up. The expanded model adds only the fraction preserving the winner against the entire corpus. Deletion removes a unique in-vocabulary term. With fewer than two such terms both features are zero. Keep zero-score and tied queries and break confidence ties by lexical query ID.

Primary endpoint is reduction in top-1 miss rate among accepted queries at exactly floor(0.70 × N) acceptance, expanded versus baseline. Advance only if the pilot reduction is at least 3 absolute percentage points and the paired two-sided 95% query-bootstrap lower limit exceeds zero. Resample complete query records 5,000 times with replacement using seed 221105 and recompute both acceptance thresholds per draw. Report standalone gap-to-10 performance as context and how often full deletion survival is below runner-only survival. Independent success requires the same reduction and interval condition on ArguAna. Phase completion is a verified SciFact receipt plus an ArguAna decision according to the gate. Both surfaces use CPU. A nonpassing pilot retires this formulation without touching ArguAna outcomes.
