# Independent leaderboard audit

Selected before reading per-item outcomes or reconstructing rankings. Stanford HELM MMLU v1.0.0 is independent of ScienceQA and One-Eval, includes a fixed test split of a multiple-choice benchmark, and publishes raw completions with reference metadata. The audit covers the v1.0.0 MMLU release and its joint multiple-choice method. The published table can use model-specific prompt changes. The unit of comparison is a published evaluation configuration. Freeze the census to all 22 configurations in the release run catalogue with one test run for each of 57 subjects. This yields 231 eligible unordered comparisons before checking archive coverage.

The prespecified target population is the five subjects also used by the separate HELM Lite design: abstract algebra, college chemistry, computer security, econometrics, and US foreign policy. The published full MMLU leaderboard is the comparator. A full-versus-five ranking change is a scope result. Independently audit the predictions on the five matched subjects using the original MMLU answer key. Check published accuracy against per-item exact match and keep official-key effects separate from scope effects. Exclude nonmatching or ambiguously bound IDs from the matched comparison and report counts. A missing raw file makes that historical arm unavailable. New runs would measure new responses even where the original weights are available.

Within each target subject, order the official question IDs by SHA-256 of UTF-8 `subject:zero-based-index` and use alternating items for first-pass and assessment panels. Compare each pair's fixed published full MMLU ordering with its matched five-subject accuracy ordering. Macro-average the five subject accuracies with equal weight for a domain-balanced score. Report the whole target descriptively after the held-out check. Held-out success requires at least one first-pass reversal that reverses in the same direction on assessment, exceeds 2 points there, and has a paired within-subject bootstrap interval lying entirely beyond zero after Bonferroni adjustment at familywise 95% across first-pass reversals. Also report unadjusted matched intervals, direction counts, ties, missing records, key replay changes, and the first-pass denominator.

If a stable reversal survives, a researcher selecting a model for a specified task mix should obtain paired scores on that mix before using the published overall ranking. The simplest explanation is model-by-subject specialization coupled with different subject weights. This predicts rank changes even when the published leaderboard has complete question coverage and a correct key. A general contribution would need evidence of consequential binding problems or an empirically useful certification rule on genuinely unmatched runs.
