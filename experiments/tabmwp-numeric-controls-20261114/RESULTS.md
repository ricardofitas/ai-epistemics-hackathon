# A correct numerical option reveals a large score-format mismatch

We asked four independent model families about the same 24 prespecified numerical TabMWP items, each once with only the correct option and once with only an incorrect option (the source answer plus one). Captures contain 192 distinct verified provider terminals, 178 complete and 14 censored, at a total API-reported cost of 0.457414. All 96 in the correct-option arm completed. Each question appears four times per arm, one per model; the scientific unit is the question.

The frozen bare-number metric accepted 1/96 in the correct-option arm. A separately specified, post-capture decoder identified the correct numerical value in **96/96**. The raw final answers comprised “A” alone (34), “A” followed by the correct value (61), and one bare correct number. All four models selected the same displayed source answer on each of the 24 questions. The number had been shown to them, so this is a positive control for scoring a selection, not a test of unaided mathematical reasoning.

In the false-option arm, the frozen bare-number metric found zero bare repetitions of the supplied false number in 82 complete answers; 14 were censored. Under the option-aware decoder, 45/96 explicitly endorsed the false option (36 letter-only, nine with its value). Another 30 gave the correct bare number. Seven supplied explanatory replies that the conservative decoder left unscored, and 14 were incomplete. The observed 45/96 is a lower bound on the proportion of all planned responses endorsing the false option; the observed 45/82 describes only completed responses. These results distinguish adopting the sole incorrect option from losing credit solely because a correct choice was returned in the requested multiple-choice format.

The option-aware analysis was added after observing answer formats and keeps the original metric alongside it. There were no judge-model calls for this re-scoring. The numerical option conditions are researcher-designed tests. The separate historical TabMWP audit operates on the original paper's public predictions and addresses a different scoring implementation.
