Use **WMT 2020’s English→German news test set, `newstest2020`** (SacreBLEU identifier: `wmt20`; language pair: `en-de`). Its news collection corresponds to late 2019. The year in the dataset name identifies the evaluation campaign, so `newstest2019` is not the right choice simply because your target articles are from 2019.

Translate the complete English source in its published order, producing one German hypothesis per source segment. Keep this test set out of training, tuning, prompt selection, and model selection. For pretrained systems, document any uncertainty about whether their training included these public data.

For a reproducible comparison:

- Score both outputs against the **same official German reference**, explicitly identifying the reference variant if alternatives are available.
- Report **case-sensitive, corpus-level BLEU using SacreBLEU**, with its standard `13a` tokenizer and detokenized German output. Avoid comparing sentence-level averages or scores produced with different preprocessing.
- Include the complete SacreBLEU signature, software version, test-set identifier, reference choice, and segment count.
- Add **chrF** as a complementary metric, and use paired bootstrap resampling for uncertainty in the difference between systems.

sacrebleu -t wmt20 -l en-de -i system.de -m bleu chrf
