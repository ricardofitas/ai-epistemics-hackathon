Use **WMT20 English→German news-test2020** (the 2020 test set), with both systems evaluated on the same released test data. The year in the set name is the task/release year; the collection period is a separate detail: WMT20’s official task page says its test sets were sampled from online newspapers from **September–November 2019**. It also says sources are original online-news text and targets are human-produced translations. For English↔German, WMT20 used paragraph-level test items, so preserve each paragraph as a segment when scoring. (WMT20 official task page, “Document-level MT” and “Development Data”: https://www.statmt.org/wmt20/translation-task.html)

For an automatic comparison, use **sacreBLEU** with the same reference(s), tokenization/default settings, and version for both outputs; report the full sacreBLEU signature along with the score so the setup is reproducible. WMT20 explicitly recommends sacreBLEU for evaluation and says it can automatically retrieve previous WMT test sets. The page also mentions the NIST tool as an option, but do not mix tools or preprocessing between systems. If you want to make a claim that one system is better, add a paired significance test over the same segments; a raw score difference alone does not establish that the difference is reliable.

WMT19 is a poor date match: its official page says its test sets came from September–November **2018**, despite the task being called WMT19. (WMT19 official task page, “Development Data”: https://www.statmt.org/wmt19/translation-task.html)
