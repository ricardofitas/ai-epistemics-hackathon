For a reproducible automatic comparison:

- Translate the identical English source sentences with both systems, preserving sentence order and document boundaries where available. Produce one German hypothesis per source sentence.
- Score **detokenized, case-sensitive corpus BLEU with SacreBLEU**, using its standard English→German `13a` tokenization and the same distributed reference configuration for both systems. Do not pre-tokenize or lowercase the German outputs.
- Report chrF alongside BLEU, and use paired bootstrap resampling to assess whether the observed difference is reliable. Treat sentence-level BLEU as unsuitable for ranking the systems overall.

```bash

  -m bleu chrf --paired-bs
```
