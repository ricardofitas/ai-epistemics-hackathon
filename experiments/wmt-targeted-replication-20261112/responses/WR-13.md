Use WMT20 English→German newstest2020 as the held-out online-news test set. The WMT20 task page states that its 2020 test sets were sampled from online newspapers from September–November 2019; it also says the English/German test set uses original online-news text on the source side and human-produced translations as targets. That directly matches a late-2019 news evaluation. The year in “newstest2020” names the task/test release, while the source-news collection period is September–November 2019. https://www.statmt.org/wmt20/translation-task.html

For an automatic comparison, score both systems’ English-to-German outputs against the same German reference with SacreBLEU. The official WMT20 page recommends SacreBLEU for evaluation and says it can automatically download prior WMT test sets. Keep preprocessing and scoring options identical for both systems, and report the SacreBLEU version/signature and corpus BLEU so the comparison is reproducible. If you specifically need a human evaluation or an exact historical WMT leaderboard reproduction, consult the corresponding WMT evaluation details; this recommendation is for a consistent automatic comparison.
