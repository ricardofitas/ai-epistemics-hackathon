Use the **WMT 2020 News Translation English→German test set, `newstest2020`**. Its news material comes from late 2019; “2020” identifies the evaluation campaign. Do not substitute `newstest2019`, and do not confuse the test set with News Crawl 2019, which is training material.

For a reproducible comparison:

- Obtain the English source and the matching official German reference through **SacreBLEU**, using test-set identifier `wmt20` and language pair `en-de`.
- Translate exactly the same source sentences with both systems, preserve their order, and output one translation per line. Supply normal, detokenized German text, with subword markers removed.
- Report **case-sensitive corpus BLEU**, using SacreBLEU’s standard `13a` tokenization. Let SacreBLEU process both hypotheses and references; do not pretokenize or lowercase them.
- Report the SacreBLEU version and complete emitted metric signature, including the reference count and reference selection. WMT reference variants can change scores, so identify the particular reference configuration rather than reporting only “WMT20 BLEU.”

A typical scoring command is:

```bash
sacrebleu -t wmt20 -l en-de   -i systemA.de systemB.de -m bleu chrf
```

Use BLEU as the conventional benchmark score and chrF as a useful complementary measure. For a claim that one system is better, add a paired bootstrap significance test over the same segments. Keep this set held out from training, tuning, and model selection.
