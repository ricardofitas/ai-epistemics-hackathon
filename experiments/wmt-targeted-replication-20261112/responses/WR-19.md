Use **WMT20 newstest2020 English→German** for the closest match to held-out online news from late 2019. The WMT20 task page says its 2020 test sets were sampled from online newspapers from **September–November 2019**, with original online-news text on the source side and human-produced translations as targets. That is the source-news period you asked for; “2020” is the task/test-set label, not the collection year. The same page identifies English–German as a task pair. citehttps://www.statmt.org/wmt20/translation-task.html

For scoring, use **sacreBLEU** on the official WMT20 English-source test set and reference, and report the sacreBLEU version and full metric signature so the comparison is reproducible. WMT20 explicitly recommends sacreBLEU for evaluating on prior WMT test sets; it also mentions the NIST tool as an option. Score both systems on identical source segments and reference, with the same preprocessing and metric settings, and report the resulting BLEU scores side by side. The page does not prescribe a particular sacreBLEU signature or a significance test, so state your choices rather than presenting them as official WMT requirements. citehttps://www.statmt.org/wmt20/translation-task.html
