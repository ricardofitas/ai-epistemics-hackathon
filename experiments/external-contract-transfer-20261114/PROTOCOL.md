# Does an inappropriate answer contract change the factual conclusion on external questions?

Preregistered 14 November 2026 before collecting this study's outputs. The MixEval 20-question diagnostic is the discovery set. This replication measures prospective transfer with published source answers. It does not identify a historical effect in another group's published results.

## Sources and design

The corpus contains 100 extractive SQuAD v1.1 development questions from 26 predeclared source topics and 100 free-response numerical TabMWP test1k questions from the authors' release. Source Git blob identities, subset eligibility, question selection, and caps are implemented in design.py. Each source contributes at most one question per passage/table and normalized question. SQuAD contributes up to six per article. Both cohorts exclude normalized matching question texts from the prior 200-row MixEval source pool. This is a project holdout relative to that pool; training exposure is unknown. Source text and aliases remain available with the model outputs for independent reanalysis. SQuAD authors Rajpurkar et al. (CC BY-SA 4.0); TabMWP Lu et al., PromptPG, original repository and license.

The same source and context, instruction position, tag request, and temperature 0 are used in all four arms. In each dataset, the hash-ordered sources are allocated alternately to a 4096- or 6144-output-token cap, balanced 50:50. Within each source the limit is the same in all four conditions and all models. Compare truncation by cap as a secondary, between-source assessment. Instruction is free response or choose an option. The cross factor is absence or presence of a single spurious A. None option. Separate standalone generation for Gemma 4 31B, Qwen3.8 27B, DeepSeek V4 Flash, and GLM-5.2 for all questions. Input order is rotated within source. No answers, answer types, gold solutions or past conversations are supplied. The first throughput windows are part of the fixed sample. The scheduler adapts solely to transport observations without selecting cases by correctness.

## Endpoints and scientific claims

Primary for each model and dataset is the source-paired drop in final-answer accuracy when A. None is added under the choice instruction. The mechanistic contrast subtracts the corresponding drop under the free-response instruction. A positive interaction supports instruction-dependent sensitivity. Also report rates of choosing the dummy answer, tag compliance and baseline accuracy. The primary endpoint is normalized exact match on the last answer tag, with the last nonempty line as prespecified fallback for nonempty completed answers. Numerical answers must agree exactly as rationals after normalizing currency, grouping separators and a declared unit. The rule does not provide a general semantic assessment of rationales. Missing, censored, HTTP-error or unauthenticated answers count as unknown in both extremes, on every planned source. Complete-case values are descriptive. Results are panel-specific. Cases, not API calls, are the units of inference.

Decision test (secondary, prospective). On SQuAD, select the highest scoring model in each of free_clear and choice_none. Evaluate each resulting choice on TabMWP free_clear, which uses source gold independently of the SQuAD decision. Treat ties/unknowns by retaining all models whose upper score reaches the highest lower score. Report conservative clean-target regret for any selected model relative to the best of the four on that target. Report a directional policy change only if both sets and target bounds justify it. The reverse direction is exploratory. No choice of metric, cases or model after inspecting outcomes.

## Credit and throughput plan

Official Adaption inference prices in credits per million input/output tokens are recorded in design.py, from https://docs.adaptionlabs.ai/inference-stacks/models/ . Fees use input plus generated tokens. A conservative per-attempt reservation uses all prompt UTF-8 bytes plus 1024 framing tokens at the uncached price and the assigned maximum output tokens. Eight serial shards of 25 sources each have independent ceilings of 10 platform credits, together at most 80 reserved credits. The full primary design reserves less than 32.4 credits before retries. The project uses the existing funded account. No credit purchase or payment action is part of the protocol.

Start each shard with a paced two-worker pilot, adapt toward four/eight workers with measured accepted throughput. Respect explicit HTTP 429, Retry-After and cooldown; at most two re-attempts only after explicit 429, with no duplicate successful or ambiguous requests. Retain all attempts. Reserve before each dispatch and update against usage; record unknown-cost outcomes conservatively. Never pool judges or traffic from other studies. The response rate, incomplete fraction, overall elapsed time including throttling, and observed token use will be reported. Account-specific USD conversion is not presumed.
