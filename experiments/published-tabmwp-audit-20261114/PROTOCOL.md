# Natural audit of the published GPT-3 and PromptPG predictions

Ricardo requested investigation that could exceed the GAMMAF finding and objected to the artificial single-option interventions. This audit uses all five released GPT-3/PromptPG prediction files at the authors' immutable source revision. It changes no question, prompt, model response or source answer. The sample scope is fixed before deriving counts for alternative parsers. The original two-shot CoT archive was inspected for schema; its recorded seed-2 score is 4,882/7,686. This is prior outcome knowledge.

1. Bind every released answer and question ID to the authors' full 7,686-question test split, and reproduce archived correctness from the released prediction using the exact source normalizer. Report any disagreement before attributing a metric effect.
2. Run the authors' actual extracted AST functions on the stored raw replies. Record deterministic extraction mismatches and any use of random fallback for out-of-range option letters. Do not treat an unverified parser replay as an identical reproduction.
3. For multiple-choice replies, keep explicit letter parsing fixed and change only the lexical fallback to case-insensitive comparison. The original comparison already lowercases at the final correctness check. A second diagnostic recognizes a unique whole-option answer after case/whitespace normalization. A third diagnostic withholds credit on residual all-zero lexical matches. Keep policy-dependent scores distinct from unequivocal string equivalence.
4. For free-response numeric replies, diagnose a conservative final-declaration rule. Extract the number only from the final explicit answer declaration and only where the remainder is the declared unit or punctuation. Keep the exact original numeric normalizer and all other outputs fixed. Each changed prediction must be archived with its raw text, source answer and previous prediction for independent assessment. This is a secondary post-discovery parser sensitivity, not a human-corrected metric.
5. Compare the published two-shot CoT baseline and PromptPG on matched source IDs under each policy. The released material may cover one seed while the paper reports a mean over three seeds. Confirm the actual release scope, and report the single-seed result without substituting it for the publication's headline mean. A surviving advantage is a negative control for a proposed explanation of that advantage.
