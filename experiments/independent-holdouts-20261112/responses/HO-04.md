Use **Natural Questions (NQ)**, an English question-answering benchmark built from real Google Search queries, paired with Wikipedia pages and human annotations. It fits the task better than benchmarks whose questions were written by annotators after reading passages. NQ includes short answer spans, yes/no answers, and cases where the supplied page has no annotated answer.

Evaluate both systems on exactly the same query–page pairs, using the original page representation rather than supplying the annotated answer-containing passage. Use the public development set, which has multiple annotations per example. Reserve a fixed portion for choosing confidence thresholds and keep the remainder untouched for the final comparison. Check that neither system was trained or tuned on those evaluation examples.

Use the **official NQ short-answer evaluator**: report precision, recall, and F1, following its rules for multiple spans, yes/no responses, acceptable annotations, and annotator agreement about answerability. Each system should provide an answer confidence so its abstention threshold can be selected on the tuning portion and then frozen. Also report answer coverage, performance on answerable versus no-answer examples, and paired bootstrap confidence intervals for the difference in F1. If yes/no answers are outside the product specification, exclude them identically and disclose that restriction.

The comparison would establish relative extraction and abstention performance on NQ’s search-query/Wikipedia-page distribution. It would not measure retrieval quality, prove that declined questions have no answer elsewhere, or establish general factual accuracy beyond this setting.
