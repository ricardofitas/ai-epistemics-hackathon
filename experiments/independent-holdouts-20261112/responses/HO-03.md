Use Google Natural Questions (NQ) as the primary resource. Its questions were submitted by real users to Google Search, and its examples pair a question with a Wikipedia page selected as relevant by annotators. NQ supplies short-answer annotations, including cases with no short answer, making it a close fit for answer-or-decline behavior. Use the Wikipedia page associated with each example as the fixed input; do not let either system retrieve a different page. If the task specifically requires evaluating a separate retrieval stage, report that as a separate experiment rather than mixing retrieval errors into extraction scores.

Create a held-out test split at the question level, deduplicate near-identical questions across splits, and freeze the page text and preprocessing. For each system, collect its answer or abstention using the same prompt, output schema, and token budget. Normalize punctuation and whitespace, then score answerable items with token-level exact match and F1 against the annotated short answer(s). Treat an abstention as correct on unanswerable items and report precision, recall, and F1 for answering answerable questions, plus abstention accuracy on unanswerable questions. Include overall accuracy and a selective-risk curve across confidence thresholds if both systems expose comparable confidence. Report paired bootstrap confidence intervals for score differences, with results broken out by answerable status.

This comparison would estimate which system extracts annotated short answers more accurately, or declines more appropriately, on this benchmark’s distribution when given the same relevant Wikipedia page. It would not establish performance on arbitrary search traffic, other sources, live retrieval, or user satisfaction; NQ’s question and page selection process may not match the intended deployment.
