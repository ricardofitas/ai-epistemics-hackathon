Scope

Keep existing events as detector-only and control_events as control-only.
Add total_events, detector_contaminated_debates and control_contaminated_debates.
Make contamination_rate_percent use combined hits / combined considered debates.
Make the unqualified mean use combined events / combined affected debates.
Expose explicit detector and control means. Correct the existing printed detector
count to use detector hits. Preserve the frozen results.json and run.log verbatim.

Expected values from the saved aggregate counts (not a new trajectory replay):

detectors: 217 / 5518 = 3.9325842697 percent; 559 events / 217 affected = 2.5760368664
controls: 323 / 1341 = 24.0865026100 percent; 1333 events / 323 affected = 4.1269349845
combined: 540 / 6859 = 7.8728677650 percent; 1892 events / 540 affected = 3.5037037037

The former global field divided 540 combined hits by 5518 detector debates.
The former mean divided 559 detector events by 540 combined hits.
The detector/control rates and per-task/per-topology rates already had coherent
denominators; they are unchanged. This patch does not change classifications,
terminal labels, EpistemicGuard inference or its leaderboard.

Regression validation

tests/test_shadow_population_counts.py covers a real two-debate exposure witness,
detector-only and control-only populations, empty input, and a controlled event
provider matching the archived population totals. The last test validates summary
aggregation, not the original event classification. Five tests passed locally.
