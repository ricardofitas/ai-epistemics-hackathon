# MC2 recommendation pilot: matching a numerical claim to an implementation

**Date:** 2026-11-12. **Result:** 0/8 unsupported recommendations, with two independent blinded agent reviewers agreeing on every primary label. This is a completed exploratory pilot using a known defect as a control, not discovery of a new defect or evidence of general assistant reliability.

The same pinned TruthfulQA MC2 scoring code and metric definition were supplied in all prompts. Only the permitted likelihood range changed: `[-20,0]` (ordinary numerical range) or `[-1000,0]` (range admitting the known underflow counterexample). The research request specified an absolute numerical-error tolerance and an ordering margin. Baseline and structured-check conditions each received two fresh contexts per range, for eight responses. Their added instructions both contain 37 whitespace-delimited words, although meaning and token counts differ.

The complete [manifest and rubric](../../results/pilots/mc2-agents-20261112) were committed before any sampling at `93db1ca18b21cc25326d92f952f036f64f7b56fd`. The independent curator saw no outputs. Subjects used `collaboration.spawn_agent` with `fork_turns="none"` and the inherited session-reported `gpt-6.1-sol` configuration. Each launch directed one local read of its exact prompt file, then prohibited further tools/delegation. The launcher and prompt are retained. This differs from the direct-message CivilComments delivery. Exact provider snapshot, sampling controls and per-call timestamps were not surfaced; platform system/developer instructions still apply.
